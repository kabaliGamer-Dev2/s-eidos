# MET-001 — viewport blocks pinch zoom

> Generated from `rules/catalog.json` by `scripts/gen-rules-docs.mjs`. Do not edit by hand.

**Classification:** `inaccessible`  
**Impact:** `accessibility`  
**Severity:** `critical`  
**Confidence:** finding `high`, remediation `high`  
**Detectability tier:** `a`  
**Autofix:** `safe`

## Why it matters

Blocking zoom removes the only way a low-vision user can enlarge text on a phone, and no content benefits from it.

## What is detected

A viewport meta tag containing user-scalable=no, or maximum-scale set below 5.

## Do not flag when

- A maximum-scale value of 5 or greater, which does not meaningfully restrict zoom
- The pattern appears in a template that is never served (documentation, a test fixture)

## Migration

```text
before: <meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no">
after:  <meta name="viewport" content="width=device-width, initial-scale=1">
```
