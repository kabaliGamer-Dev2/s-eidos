# FRM-001 — autocomplete disabled on a credential field

**Detectability tier:** `b`  
**Autofix:** `situational`

## Why it matters

Browsers do not stop password managers because of autocomplete=off, so the attribute buys nothing while blocking the helpful autofill path and the correct field-purpose metadata.

## What is detected

An input with autocomplete="off" whose type is password, or whose name or id suggests a credential field.

## Do not flag when

- A genuinely one-time value that must not be stored, such as an OTP, where autocomplete="one-time-code" is the better answer than off
- A search field, where off is a legitimate preference

## Migration

```text
before: <input type="password" name="password" autocomplete="off">
after:  <input type="password" name="password" autocomplete="current-password">
```

Use current-password or new-password so the browser offers the right behaviour.
