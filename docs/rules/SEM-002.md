# SEM-002 — javascript: URL in a link or source

## Why it matters

A javascript: URL executes script in the page's origin, is blocked by a Content-Security-Policy that forbids inline script, and is an injection sink whenever the value is not fully trusted.

## What is detected

An href or src value (quoted HTML attribute or JSX string literal) whose scheme is javascript:.

## Do not flag when

- The literal appears inside a comment or a documentation string
- A test asserts that such a value is rejected

## Migration

```text
before: <a href="javascript:void(0)" onclick="save()">Save</a>
after:  <button type="button" onclick="save()">Save</button>
```

When the element genuinely navigates, use a real URL; when it performs an action, use a button.

## Support

Applies regardless of the declared target.
