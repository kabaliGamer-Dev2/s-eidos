# ARI-001 — Large motion ignores prefers-reduced-motion

## Why it matters

Motion sickness is a real vestibular response; a blanket animation that ignores the user's stated preference can make a page unusable for them.

## What is detected

Two or more transform or animation declarations in a file that has no prefers-reduced-motion media block.

## Do not flag when

- Motion is limited to a short opacity fade, which is not a vestibular trigger
- The reduced-motion guard lives in a shared stylesheet outside the scanned paths
- The motion is a canvas or video background the author cannot express in CSS

## Migration

```text
before: .card { transition: transform 400ms; }
after:  @media (prefers-reduced-motion: reduce) { .card { transition: none; } }
```

## Support

Requires the `prefers-reduced-motion` feature at `safari-16-plus` or newer.
