# IMG-001 — img has no intrinsic dimensions

> Generated from `rules/catalog.json` by `scripts/gen-rules-docs.mjs`. Do not edit by hand.

**Classification:** `obsolete`  
**Impact:** `performance`  
**Severity:** `medium`  
**Confidence:** finding `medium`, remediation `high`  
**Detectability tier:** `b`  
**Autofix:** `none`

## Why it matters

Without width and height the browser cannot reserve space before the image loads, so content jumps and the layout shift is charged to the page.

## What is detected

An img element with neither width nor height, in a file where no aspect-ratio is visible, and which is not a framework image component that reserves space itself.

## Do not flag when

- The image is rendered by next/image with fill, which requires absolute positioning and supplies its own sizing contract
- The dimensions arrive through a design-system wrapper component rather than the tag
- A stylesheet sets aspect-ratio for this element's class

## Migration

```text
before: <img src="/hero.jpg" alt="Product" />
after:  <img src="/hero.jpg" alt="Product" width="1200" height="630" />
```

Add the real intrinsic ratio; CSS can still size the rendered box.

## Support

Applies regardless of the declared target.
