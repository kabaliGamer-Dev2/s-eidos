# SEM-001 — iframe has no accessible name

> Generated from `rules/catalog.json` by `scripts/gen-rules-docs.mjs`. Do not edit by hand.

**Classification:** `inaccessible`  
**Impact:** `accessibility`  
**Severity:** `medium`  
**Confidence:** finding `high`, remediation `medium`  
**Detectability tier:** `a`  
**Autofix:** `none`

## Why it matters

A frame without a name is announced as an unnamed frame, so a screen-reader user cannot tell what it contains before entering it.

## What is detected

An iframe start tag whose attribute list contains none of title, aria-label or aria-labelledby.

## Do not flag when

- A decorative frame that sets aria-hidden="true" on itself and holds no interactive content
- A frame whose accessible name is supplied by a wrapper component that spreads the attribute at runtime

## Migration

```text
before: <iframe src="/map" />
after:  <iframe src="/map" title="Office location map" />
```

The title must describe the frame's content; it cannot be generated automatically.

## Support

Applies regardless of the declared target.
