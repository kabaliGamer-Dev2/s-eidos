# TYP-001 — @ts-ignore instead of @ts-expect-error

> Generated from `rules/catalog.json` by `scripts/gen-rules-docs.mjs`. Do not edit by hand.

**Detectability tier:** `a`

## Why it matters

@ts-expect-error fails when the error disappears, so the suppression removes itself; @ts-ignore silently outlives the bug it was hiding.

## What is detected

A // @ts-ignore or /* @ts-ignore */ comment.

## Do not flag when

- The suppression targets a line that will never produce an error by design (for example a generated declaration file). The rule still reports it; use a reasoned decision record to suppress the finding.

## Migration

```text
before: // @ts-ignore
after:  // @ts-expect-error -- value is populated by the loader above
```

## Support

Requires typescript `>=3.9`.
