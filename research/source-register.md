# Source register — master citation list for the v0.1 rule catalog

**Purpose:** one deduplicated row per exact URL so the catalog's `Evidence URL` cells and every other artifact can be link-checked in one pass. **Retrieved:** 2026-11-16 (Asia/Calcutta) for every row below; `Retrieved` is repeated per row because the link checker keys on it.

## 0. Columns, authority tiers, status vocabulary

| Field | Meaning |
|---|---|
| `Authority` | `A` primary structured data (BCD JSON, webstatus API, registry metadata, spec text); `B` first-party prose (MDN/MDN guides, react.dev, nextjs.org, web.dev, vendor release notes, W3C/WAI explainers, OWASP); `C` aggregator (caniuse); `—` not evidence. Uses the tier table in `research/agents/modern-web-researcher/citation-discipline.md` §1. |
| `Used by` | `CAT` = `legacy-pattern-catalog.md`; `FW` = `framework-guidance.md`; `CWP` = `current-web-practices.md`; `BCM` = `browser-compatibility-matrix.md`; `QSB` = `quality-security-baseline.md`. |
| `Status` | `FETCHED-BY-INPUT` = a specialist input states the page was opened 2026-11-16; `CITED-BY-INPUT` = canonical path supplied by a specialist but not re-opened (the integrator opened no URL); `UNVERIFIED` = an input explicitly marks the fact or the reachability unresolved; `DEAD` = HTTP 404, must never ship. |
| `Notes` | Why the row exists, the specific claim it supports, and any qualifier that must survive into output text. |

`UNVERIFIED` is a legitimate value. No row below was asserted from memory: every row is present in one of the six input artifacts. The integrator added no new URL.
