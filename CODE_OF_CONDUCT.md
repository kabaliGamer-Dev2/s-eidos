# Code of conduct

## The short version

Be decent. Assume the other person is trying. Critique code and claims, never people.

## Expected behaviour

- **Argue with evidence.** This project is built on citations; disagreements are settled by pointing
  at a source, a reproduction, or a test — not by repeating an opinion more firmly.
- **Report false positives precisely.** "This is noisy" is a start; the smallest snippet that
  reproduces it plus the correct verdict is what makes it fixable.
- **Respect the premise.** S-Eidos exists to stop indiscriminate modernisation. A proposal that
  flags code merely for being old is out of scope by construction, not a matter of taste.
- **Give credit.** If a rule, fixture or test came from someone else, say so in the pull request.
- **Accept a "no" gracefully.** A rule may be rejected because its citation is weak, its detector is
  imprecise, or another project already owns the ground. That is a technical judgement, not a
  judgement of you.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, sustained disruption, publishing someone's
private information, and dismissing a report of the above.

## Scope

This applies to issues, pull requests, discussions, commit messages, and any other space where you
are representing the project.

## Reporting

Report a concern privately to the maintainer listed on the repository profile. Reports are handled
confidentially. The maintainer may warn, remove content, or block an account, and will say why.
